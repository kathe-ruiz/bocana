Pega la URL de tu Google Apps Script Web App para sincronizar cada pulsera automáticamente.

Ver instrucciones ▾

1. Abre script.google.com → Nuevo proyecto

2. Pega el código del archivo bocana-apps-script.js

3. Cambia TU_SHEET_ID_AQUI por el ID de tu Sheet

4. Implementar → Nueva implementación → App web → Acceso: Cualquier persona

5. Copia la URL y pégala arriba
